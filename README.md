# MultiAgent
Multi Agent Simulation Framework

A full-stack application for running multi-agent simulations with a React frontend and Python backend.

## Prerequisites

- **Node.js** >= 18.0.0
- **Python** 3.8+
- **MongoDB** (for backend database)
- **OpenAI API Key** (for LLM functionality)

## Project Structure

- `frontend/` - React application with Vite
- `backend/` - Python Flask API server

## Quick Start

### Backend Setup

For detailed backend setup instructions, see [backend/README.md](backend/README.md)

### Frontend Setup

For detailed frontend setup instructions, see [frontend/README.md](frontend/README.md)

## Development Workflow

1. **Start Backend**: Follow the setup instructions in `backend/README.md`
2. **Start Frontend**: Follow the setup instructions in `frontend/README.md`
3. **Access Application**: Visit the localhost link provided in terminal in your browser

The frontend will communicate with the backend API to manage and visualize multi-agent simulations.

## API Documentation

The backend provides a comprehensive REST API for managing simulations. For detailed API documentation including all endpoints and request/response formats, see [backend/README.md](backend/README.md).
